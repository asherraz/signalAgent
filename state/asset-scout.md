# Asset scout agent — state

## 2026-08-28 — first run

**Scope this run:** Per operator instruction — start with jRCT via the JPRN portal; screen for completed interventional trials with efficacy endpoints, held by Japanese academic institutions or companies with no US presence.

**Access problem, recorded up front:** jRCT could not be searched this run, at either entry point.

- **JPRN portal** (rctportal.mhlw.go.jp/s) — the advanced-search form loads and its fields could be filled (progress status, clinical-research classification, region), but every submission of the detailed search — via the in-page submit button and via a hand-built GET request replicating the form's own field names — returned either a CakePHP application error (HTTP 500, generic production error page, no detail) or a CloudFront 504 Gateway Timeout. This was consistent across multiple attempts, including a final recheck at the end of the run. The plain free-word search on the same portal was not tested independently of the detailed-search failure. This looks like a genuine origin-server problem, not a request-shape problem — worth a straight retry on a future run rather than more workaround engineering.
- **jRCT direct** (jrct.niph.go.jp) — TLS handshake fails at connect time (`SSLV3_ALERT_HANDSHAKE_FAILURE`), confirmed both via direct `curl` and via the browser tool's own navigation, on an AWS-fronted IP range. This reads as bot/TLS-fingerprint mitigation in front of jrct.niph.go.jp specifically, not a general network problem — the JPRN portal and UMIN-CTR, both on different infrastructure, were reachable throughout.

Given jRCT was unreachable by both routes, this run used **UMIN-CTR** (umin.ac.jp / center6.umin.ac.jp) as the primary source instead. UMIN-CTR's advanced search (Study type, Basic objectives, Recruitment status, Region) is a close match for the brief's screening criteria and was fully usable. This is a real gap against the brief, not a substitute for it — jRCT is the brief's stated main source and UMIN skews toward investigator-initiated and academic trials, so **industry-sponsored jRCT-only trials are under-represented in what got screened this run.** Retry jRCT first on the next run before falling back to UMIN again.

**What was searched:** UMIN-CTR advanced search, Study type = Interventional, Recruitment status = Completed, Region = Japan, Basic objectives = Safety,Efficacy, Phase = III. This returned ~280 trials across 3 result pages; pages 1 and 2 (~180 trials, back to 2012) were read in full. Page 3 (older trials) was not reached this run.
