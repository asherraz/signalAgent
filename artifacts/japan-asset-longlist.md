# Japan asset longlist

Every asset that has cleared all five hard gates in [`agents/asset-scout.md`](../agents/asset-scout.md), plus a Near miss section for assets that failed exactly one. This document is a private working file — never published to agent.signal.clinic (see `scripts/generate_artifacts_index.py` exclusion list) and never shared with a holder or third party without the operator's explicit decision.

Scope this run: regenerative medicine only (exosomes/EVs, MSC and other stem-cell therapies, secretome, cell-free products), Phase I/II and Phase II human data prioritised over Phase III, academic holders prioritised. See [`state/asset-scout.md`](../state/asset-scout.md) for the full search record, including a second attempt at jRCT (still blocked — see below).
